文献罗盘是一款科研文献调研与阅读工具。沿参考文献追溯研究基础，沿施引文献跟踪后续进展；结合研究主题与文献指标筛选候选论文，再通过 AI 翻译、概括和全文导读理解内容，将发现与阅读判断整理成自己的专题。

适用于研究生开题、课题组新成员入门、研究方向拓展和综述准备。

![文献罗盘工作界面](docs/images/workspace.png)

## 让发现、阅读和整理连起来

1. **发现文献**：从一篇或多篇种子论文出发，双向拓展参考文献与施引文献，查看研究脉络和发现路径。
2. **筛选重点**：结合主题相关性、年份、被引数和期刊指标比较候选论文，按需切换图谱或列表。
3. **理解内容**：翻译题名和摘要，归纳研究问题、方法、结果与贡献；进一步阅读逐节解读、图表说明和原文依据。
4. **沉淀专题**：通过多级文件夹、拖拽归类和阅读备注整理专题，再导出阅读成果。

## 开始使用

需要 **Python 3.11+**。下载源码后，Windows 用户可双击 `start.bat` 启动；也可在终端运行：

```bash
python -m venv .venv
# Windows
.venv\Scripts\activate
# macOS / Linux: source .venv/bin/activate
pip install -r requirements.txt
python -m app.main
```

浏览器打开 **http://127.0.0.1:8765**。

1. **导入文献**：使用 DOI、BibTeX、RIS、PDF 文件夹或 Zotero。
2. **选择起点**：选择已知论文，开始双向引文拓展。
3. **筛选与阅读**：查看图谱、比较指标，使用 AI 速览或全文解读。
4. **归入专题**：建立文件夹，将文献拖入分类，整理阅读清单并导出。

## 配置 AI

打开 **数据与设置 → 模型连接**，选择服务，填写模型名称和 API 密钥，保存后点击 **测试连接**。可保存多组连接，随时切换、编辑或删除。

当前支持 DeepSeek、OpenAI 与浙江大学模型服务。已有生成结果可以直接查看；新内容在点击生成后处理。密钥保存在用户数据目录，页面不回显。

## 专题与阅读清单

- 文献库与阅读清单分别管理文件夹，支持子文件夹、重命名、颜色标记和目录移动。
- 同一篇文献可加入多个专题；通过拖拽、多选或右键菜单完成归类。
- 使用“未分类”和文件夹搜索快速整理，按需包含子文件夹中的文献。
- 支持移动、移出和最近一次整理的撤销；删除文件夹会保留文献及 PDF。
- 两个工作区各有回收站，支持批量恢复、原分类和备注恢复。默认保留 30 天，可修改天数，设为 0 则持续保留。
- 到期后将恢复包转入 Windows 回收站，不彻底删除；软件关闭期间到期的内容在下次启动时处理。原始 PDF 与 Zotero 原库不移动，转出失败时继续保留。其他系统暂保留在软件回收站。

## 有依据地辅助阅读

**资料补全**可按篇或批量补充书目、期刊指标与中文内容，已有人工内容保持原样。支持配置 OpenAlex、easyScholar，或导入已有期刊指标缓存；缺失数据与指标年份单独标注。

**全文导读**需要可提取文本的 PDF。在阅读窗口查找 Zotero 附件、下载公开全文或上传本机 PDF 后，在详情中选择“AI 全文解读”，即可依次阅读摘要与引言、逐节解读、图表说明、结论与局限，并按页码核对原文依据。结果可导出为含 Markdown 和图片的 ZIP。扫描件需先完成 OCR；AI 输出应结合论文原文判断。

## 文献管理与导出

支持 CSV、RIS、GraphML 导出，以及 Zotero 授权同步；可选择目标集合，查看同步位置并迁移到其他集合。源码更新与用户数据分开管理，升级前请备份完整数据目录，参见[升级说明](docs/UPGRADING.md)。
