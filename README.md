文献罗盘是一款 AI 辅助的科研文献调研与阅读工具。沿参考文献追溯研究基础，沿施引文献跟踪后续进展；结合研究主题与文献指标筛选候选论文，再通过 AI 翻译、概括和全文导读理解内容，将发现与阅读判断整理成自己的专题。

适用于研究生开题、课题组新成员入门、研究方向拓展和综述准备。

![文献罗盘工作界面](docs/images/workspace.png)

## 让 AI 辅助阅读融入文献调研

- **双向引文拓展，建立阅读范围**：从已知论文追溯研究基础、跟踪后续进展，围绕研究问题发现值得进一步阅读的文献。
- **AI 双语速览，快速理解候选论文**：翻译题名、概括摘要，归纳研究问题、方法、结果与贡献，并通过原文引用核对依据。
- **AI 全文解读，衔接深入阅读**：围绕 PDF 逐节解读研究内容，说明图表、结论与局限，按页码返回原文查看。
- **AI 辅助补充中文内容，保留整理成果**：在有原文依据时补充缺失的译文与概括，再通过专题文件夹和阅读备注积累研究资料。书目与期刊指标由学术数据源补充。

## 开始使用

需要 **Python 3.11+**。下载源码后，Windows 用户可双击 `start.bat` 启动；也可在终端运行：

```bash
python -m venv .venv
# Windows
.venv\Scripts\activate
# macOS / Linux: source .venv/bin/activate
pip install -r requirements.txt
python -m app.main
```

浏览器打开 **http://127.0.0.1:8765**。

1. **导入文献**：使用 DOI、BibTeX、RIS、PDF 文件夹或 Zotero。
2. **选择起点**：选择已知论文，开始双向引文拓展。
3. **筛选与阅读**：查看图谱、比较指标，使用 AI 速览或全文解读。
4. **归入专题**：建立文件夹，将文献拖入分类，整理阅读清单并导出。

## 配置 AI

打开 **数据与设置 → 模型连接**，选择服务，填写模型名称和 API 密钥，保存后点击 **测试连接**。可保存多组连接，随时切换、编辑或删除。

可连接 **DeepSeek、OpenAI** 等模型服务，也可自定义接入兼容 OpenAI 接口的服务。已有生成结果可以直接查看；新内容在点击生成后处理。密钥保存在用户数据目录，页面不回显。

## 文献库与阅读清单

**文献库**用于积累研究资料、构建专题。通过多级文件夹、拖拽归类和跨专题收录，把分散文献组织成可持续整理的研究资料库。

**阅读清单**用于集中管理选中的候选论文，保留阅读备注与筛选判断，衔接精读和综述整理。两个工作区均提供回收站与误删恢复。

详细操作见[功能说明书](docs/USER_GUIDE.md)。

## 资料补全与 AI 阅读

- **资料补全**：按篇或批量补充书目、期刊指标与中文内容，保留已有人工整理。
- **AI 速览**：翻译题名、概括摘要，归纳研究问题、方法、结果与贡献，点击引用核对原文。
- **全文解读**：查找附件、下载公开全文或上传 PDF 后，生成逐节导读与图表说明，按页码查看依据并导出阅读成果。

## 文献管理与导出

支持 CSV、RIS、GraphML 导出，以及 Zotero 授权同步；可选择目标集合，查看同步位置并迁移到其他集合。
