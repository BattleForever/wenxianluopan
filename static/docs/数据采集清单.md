# 文献罗盘 数据采集清单

> 目标：让你能按本清单**逐项采集**文献信息，填进两张标准表（papers.jsonl / citations.jsonl），最后导入文献罗盘，存成本地 SQLite 数据库（`data/papernet.db`），图谱、推荐、详情全部直接可用——**全程无需联网**（联网只是可选的自动补全捷径）。

---

## 一、完整引用网络需要哪三张表

```
┌─────────────────────┐        ┌─────────────────────┐
│  papers.jsonl       │        │  citations.jsonl    │
│  （文献表，一行一篇）  │ ───1:N──▶ │  （引用边表，一行一条） │
│  谁写的、哪年、讲什么   │        │  谁引用了谁          │
└─────────────────────┘        └─────────────────────┘
          │                               │
          ▼                               ▼
   图谱的「节点」                    图谱的「边/箭头」
```

- **节点** = papers 表里每篇文献
- **边** = citations 表里每条“A 引用 B”（A→B 画箭头）
- 附加的收藏集（collections）在软件界面里建即可，不用文件

---

## 二、papers 文献表字段清单（按采集优先级）

### ★★★ 必须采集（没有就进不了网络）

| # | 字段 | 类型 | 说明 | 采集来源建议 |
|---|------|------|------|--------------|
| 1 | `title` | 文本 | 英文/原文标题 | 论文首页；CNKI 导出 |
| 2 | `title_zh` | 文本 | 中文标题（英文文献可留空，或自译） | CNKI/万方；自译 |
| 3 | `doi` | 文本 | **最重要的连接键**，引用边全靠它对齐 | 论文首页/页脚；Crossref 搜标题 |
| 4 | `year` | 整数 | 发表年份（图谱过滤、着色用） | 论文首页 |
| 5 | `references` | DOI 列表 | **该文献引用了谁**（出边，一行里直接写） | 论文参考文献表逐条对 DOI；CNKI 引文导出 |

> `references` 写在 papers.jsonl 每一行里（推荐，采集省事）；也可以单独汇总到 citations.jsonl，两种方式等价。

### ★★ 强烈建议（决定详情面板和推荐质量）

| # | 字段 | 类型 | 说明 | 采集来源建议 |
|---|------|------|------|--------------|
| 6 | `abstract` | 文本 | 英文摘要 | 论文首页 |
| 7 | `abstract_zh` | 文本 | 中文摘要 | CNKI/万方；自译 |
| 8 | `authors` | 列表或分号串 | 作者，如 `"张三; 李四"` 或 `["张三","李四"]` | 论文首页 |
| 9 | `venue` | 文本 | 期刊/会议名 | 论文首页 |
| 10 | `keywords` | 列表或分号串 | 关键词（详情展示、未来可做标签过滤） | 论文首页/数据库导出 |

### ★ 可选（有就更好）

| # | 字段 | 类型 | 说明 | 采集来源建议 |
|---|------|------|------|--------------|
| 11 | `cited_by_count` | 整数 | 被引总数（决定节点大小、列表排序） | 知网/谷歌学术；不填默认 0 |
| 12 | `local_pdf_path` | 文本 | 本地 PDF 完整路径（**只登记，软件不移动不修改**） | 你的 PDF 文件夹 |
| 13 | `oa_pdf_url` | 文本 | 开放获取 PDF 网址（可在软件里一键下载） | OpenAlex/期刊官网 |
| 14 | `type` | 文本 | 类型：journalArticle / thesis / patent / conference / standard… | 数据库导出 |
| 15 | `openalex_id` | 文本 | OpenAlex 编号（若联网匹配过，软件会自动填） | 自动 |
| 16 | `status` | 文本 | `library`（正式库内，默认）或 `candidate`（候选）。**批量导入"仅被引文献"时请填 `candidate`**，不占用正式文献库 | — |
| 17 | `zotero_key` | 文本 | Zotero 条目 Key（8 位），用于与 Zotero 同步结果对齐 PDF 路径 | 自动 |
| 18 | `collections` | 列表或分号串 | 收藏集名称（软件自动创建收藏集并把该文献入集），最多 10 个 | 你的分类体系 |

> **偷懒路线**：英文文献只要给 DOI 列表，软件联网会自动补全 ★★★ 里除 references 外的全部字段和被引数据；只有 OpenAlex 覆盖不到的（大部分中文期刊文献、最新论文、专利、学位论文）才需要手工采集。

## 三、citations 引用边表（单独文件，可选）

一行一条，适合把零散查到的引用关系汇总在一起：

```json
{"citing": "10.1234/abc", "cited": "10.5678/def"}
```

| 字段 | 说明 |
|------|------|
| `citing` | 引用方的 DOI（或与 papers 表一致的标题） |
| `cited` | 被引方的 DOI（或标题） |

## 三·补充、venues 期刊/会议等级表（单独文件，可选但强烈建议）

决定"这个发表载体有多强"。导入后在详情面板显示金色徽章（IF / JCR 分区 / 中科院分区 / TOP / CCF 等级），并可在「数据库」页按表浏览、导出 venues.csv。

```json
{"name":"Nature","kind":"journal","impact_factor":"50.5","jcr_zone":"Q1","cas_zone":"1区","cas_top":"是","cas_sub":"综合性期刊 1区","source":"easyscholar"}
{"name":"CVPR","kind":"conference","ccf_tier":"CCF-A","source":"CCF推荐目录"}
```

| 字段 | 说明 |
|------|------|
| `name` | 期刊/会议**全名**，需与 papers 表 `venue` 字段写法一致（软件按归一化名称匹配，忽略大小写和标点） |
| `kind` | `journal`（期刊）或 `conference`（会议） |
| `impact_factor` | 影响因子，文本（如 "50.5"），随年份变化取最新 |
| `jcr_zone` | JCR 分区（Q1–Q4） |
| `cas_zone` | 中科院大类分区（1区–4区） |
| `cas_top` | 中科院 TOP 期刊："是"/"否" |
| `cas_sub` | 中科院小类分区（如 "工程:电子与电气 1区"） |
| `ccf_tier` | 会议/部分期刊等级：CCF-A/B/C、CORE-A* 等，自由文本 |
| `source` | 数据来源（easyscholar / LetPub / CCF推荐目录 / 手动） |
| `note` | 其他信息（ESI、h5 指数等），存入附加元数据 |

> 也支持在 papers.jsonl 每行内直接写 `"venue_meta": {...同上结构但不带 name...}`，导入时自动挂到该行 `venue` 指向的期刊/会议。
> 数据源建议：easyscholar 浏览器插件导出、LetPub 影响因子查询、中科院分区表官方平台、中国计算机学会（CCF）推荐国际学术会议和期刊目录。
> 重复导入自动合并：同名载体已有信息不会被覆盖，只补空缺字段。

## 四、文件格式规范

- 编码：**UTF-8**（记事本/VS Code 另存为 UTF-8；Excel 请用「导出 CSV-UTF8」再转，或直接用记事本编辑）
- 每行一个独立 JSON 对象，行尾无逗号；空行忽略
- 未知字段会被自动忽略并在导入报告里提示

### papers.jsonl 完整示例（一英文一中文）

```json
{"doi":"10.1109/CVPR.2016.90","title":"Deep Residual Learning for Image Recognition","authors":"Kaiming He; Xiangyu Zhang","year":2016,"venue":"CVPR","abstract":"Deep residual learning...","cited_by_count":229180,"references":["10.1007/978-3-319-46493-0_38","10.1109/ICCV.2015.169"]}
{"doi":"10.6045/zxxx.2024.001","title":"Guided-wave ultrasonic gas flow sensing: a review","title_zh":"导波式超声管道气体流量感知研究综述","authors":"王五; 赵六","year":2024,"venue":"仪器仪表学报","abstract":"Ultrasonic guided waves...","abstract_zh":"超声导波在管道气体流量测量中…","keywords":["超声导波","气体流量","管道"],"cited_by_count":3,"type":"journalArticle","local_pdf_path":"D:\\literature\\导波超声综述.pdf","references":["10.6045/zxxx.2019.077"]}
```

### citations.jsonl 示例

```json
{"citing":"10.1109/CVPR.2016.90","cited":"10.1007/978-3-319-46493-0_38"}
{"citing":"10.6045/zxxx.2024.001","cited":"10.6045/zxxx.2019.077"}
```

## 五、推荐工作流

1. **先导英文种子**：把已有 DOI 粘到「① DOI 导入」，联网自动补全（一次即可，之后全离线可用）。
2. **中文文献逐篇采集**：从知网导出题录（Refworks/自定义格式含中英文标题摘要），对照第二节清单填进 papers.jsonl；参考文献表里的中文文献往往没有 DOI——此时在 `references` 里写与 papers 表一致的中文标题即可，软件按标题对齐。
3. **引用边**：论文参考文献表逐条核 DOI 填进 `references`；零散查到的关系放 citations.jsonl。
4. **导入**：导入页「⑥ 标准数据表」，粘贴或选文件 → 导入报告会列出：新增几篇、新增几条边、**未解析引用**（对方 DOI/标题不在库里——把它补进 papers 或修正拼写）。
5. **建网/看图**：收藏集建一个装这批文献，图谱页看网络；缺的被引数据可点「构建网络」联网补。

## 六、去重与对齐规则（采集时注意）

- DOI 一律小写、去掉 `https://doi.org/` 前缀后对齐（软件自动做，你不用管大小写）
- 没有 DOI 的文献按**标题**对齐：标题必须与 papers.jsonl 里写的一字不差（忽略空格和大小写）
- 同一篇出现两次不会重复入库，会自动合并、字段取非空的补全

## 七、数据存在哪

- 全部数据：`papernet/data/papernet.db`（SQLite，可用任何 SQLite 工具直接读取/备份）
- 下载的 PDF 副本：`papernet/data/pdfs/`
- 你的原始 PDF/Zotero 文件只登记路径，**永不被修改或删除**
