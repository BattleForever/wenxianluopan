④ 本地 PDF 文件夹

自动提取 PDF 内嵌 DOI / 标题并匹配 OpenAlex；只读取你的 PDF，绝不修改或删除。

⑥ 标准数据表导入（自采集 JSONL，支持纯中文文献）

按 docs/数据采集清单.md 的字段规范逐条采集，存成 papers.jsonl（一行一篇）和 citations.jsonl（一行一条引用边 {"citing":"DOI","cited":"DOI"}），UTF-8 编码。引用两端也接受与 papers 一致的标题。

⑤ Zotero 本地库同步（只读）

需要 Zotero 7 正在运行，并在设置中启用 Zotero 集成。只读取条目与 PDF 路径，不写入 Zotero。选分类时含其全部子分类。

SQLite 库文件：

        推荐工具：DB Browser for SQLite（免费图形界面）、VS Code 的 SQLite 插件、或命令行 sqlite3。表结构见上方各表浏览；papers 是文献表、citations 是引用边表（from_id 引用 to_id）、fetch_cache 是联网抓取缓存（可安全清空）。

      

    


    
    

      

        
网络与隐私

        
        
        
联网时仅访问固定白名单域名：api.openalex.org、opencitations.net、api.crossref.org、api.semanticscholar.org、easyscholar.cc，以及下载 OA PDF 时的开放仓储（arxiv.org、PubMed Central、bioRxiv 等）；只发送 DOI/标题查询，库内容不上传，结果全部缓存到本地。
