# 0.9.0 产品验收范围

以真实页面操作和来源记录验收，不用单一完成百分比替代产品质量。

1. 悬停节点尺寸不变；参考与施引关系使用两种颜色，箭头和图例明确。
2. 1366×768、1440×900、1920×1080 下底部操作区可见、可点击。
3. 适配恢复放大和平移后的完整图谱，容器变化后更新尺寸并反馈结果。
4. 高级选项独立展开，主控件保持对齐，无重叠或溢出。
5. 分区筛选展示可用计数与缺失数量，支持中科院/JCR 区分，不将缺失当作零。
6. 年份控件默认范围 2020–当前年；未启用时不隐式排除早期文献。
7. 单篇和批量补全取得书目、期刊指标和 AI 中文内容；记录来源、年份和失败原因，不覆盖已有人工内容。
8. 点击空白和切换页面关闭详情，延迟请求不得重新打开旧文献。
9. 模型配置支持列表、新建、编辑、启用、删除及单项测试；密码不回显，删除后不自动恢复外部旧配置。

真实模型和网络验证使用公开论文，真实 Zotero 库保持只读。发布前扫描源码、归档及 Git 历史，排除用户材料、运行数据、个人标识和实际密钥。
