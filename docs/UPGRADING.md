# 版本与数据管理

源码版本使用 Git 标签固定，旧版本保持可回退。近期更新见根目录 CHANGELOG.md。

## 升级

1. 关闭正在运行的文献罗盘。
2. 备份完整数据目录。默认是程序目录中的 `data/`；使用自定义数据目录时备份所指定的位置。备份应包含数据库、导入文件、AI 设置和生成时的 PDF 快照。
3. 更新源码并重新安装 requirements.txt 中的依赖，保持原数据目录设置不变。
4. 启动后在网页核对文献数量、阅读备注和已有 AI 结果。升级不会自动重新生成或自动重发中断的模型任务。

0.8.0 采用增量数据库迁移，保留现有书目、引用和缓存。新版本保存生成来源快照；旧版缓存未保留快照时，重新生成即可启用绑定快照的原文核对和图片导出。

0.9.0 新增资料补全任务与字段来源表，保留已有内容。补全任务在服务重启后标记为中断，已填入的字段不会回滚，也不会自动重发模型请求。

0.10.0 新增文献库与阅读清单的多级文件夹和回收站。旧收藏集首次打开时迁入文献库文件夹；旧阅读备注保留。回收站默认保留30天，两个工作区可分别修改，设为0可持续保留。Windows 下到期文献会生成恢复包并转入电脑回收站，原始 PDF 与 Zotero 原库不移动。转出失败或不支持此操作的系统继续保留内容，不会改为彻底删除。应用启动时及运行期间每小时检查到期项。

软件另行保留已转出文献的恢复索引，可在回收站“已转出记录”中恢复。请继续备份完整数据目录；恢复包不替代数据目录备份。若回退到0.9.0或更早版本，旧版不识别新的回收站状态，可能再次显示已删除条目，建议同时使用对应的升级前数据备份。

首次读取旧模型配置时，将其显示为「已有模型连接」。在网页保存、切换或删除连接后，配置写入数据目录的 `private/ai_config.local.json`，其中同时保留旧版读取所需的激活模型字段。删除最后一个连接会保留空配置，避免外部旧密钥自动恢复。数据源凭据单独保存在同目录的 `data_sources.local.json`。备份与迁移时连同整个数据目录保留。

0.11.0 支持在网页连接 Zotero 并保存本机授权，选择同步集合和迁移已同步位置。授权保存在用户数据目录的 `private/zotero.local.json`，备份与迁移时一并保留，不要公开分享。补全任务与已保存的结果继续保留。

## 回退

停止程序后检出所需的已发布标签。若需恢复升级前的完整状态，使用升级前备份的数据目录；不要用空目录覆盖已有文献库。源码归档不包含用户数据和配置，GitHub 上的版本切换也不会备份本机数据。

## 验证

```bash
python tests/run_all.py
```

各套件在独立进程中运行，使用合成数据和模拟服务，不请求真实模型或写入真实 Zotero 库。浏览器回归为可选检查，安装 Playwright 与 Chromium、启动一个测试实例后运行：

```bash
python tests/browser_smoke.py --base http://127.0.0.1:8765
```
