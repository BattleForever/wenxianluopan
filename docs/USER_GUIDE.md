# 文献罗盘功能说明书

文献罗盘围绕“发现文献 → 筛选候选 → 理解内容 → 整理专题”组织工作。第一次使用可先导入几篇已知论文，再选择其中一篇作为引文拓展的起点。

页面上的“小书灵”是统一任务入口，保持在详情侧栏和弹出窗口上方可用。按住角色可拖动，松手后记住位置；同一浏览器刷新或重新打开页面时会恢复。旁边显示最近任务，点击可查看全部任务与结果。键盘聚焦角色后，用方向键移动；开启系统减少动态效果设置时，角色会停止循环动画。

Windows 下双击 `start.bat` 启动；首次会自动安装依赖，请保持联网。服务就绪后自动打开页面。双击 `create-shortcut.bat` 可创建桌面入口；之后双击桌面“文献罗盘”即可启动或打开正在运行的软件。源码目录移动后需重新创建快捷方式。

## 1. 导入与选择起点

在“导入文献”中，可使用 DOI、BibTeX、RIS、PDF 文件夹或 Zotero 导入资料。导入后，在文献探索页选择一篇或多篇种子论文，也可在文献详情中点击“设为扩展种子”。

## 2. 双向引文拓展

- **参考文献**：向前追溯研究基础、方法来源与早期工作。
- **施引文献**：跟踪引用该论文的后续研究。
- **双向追踪**：同时展开两种关系，围绕种子论文建立专题网络。

点击“拓展设置”选择方向和轮次。一轮查询种子的直接参考文献和施引文献，两轮再向外探索一层。新任务保留所选范围内全部已观察到的候选，不因排名低或期刊指标缺失而丢弃。联网查询优先核查种子直接关系，再结合引文与主题证据安排后续分支；查询预算控制本轮工作量，不作为候选数量上限。预算用完后，在小书灵的任务列表点击“继续探索”可查询尚未处理的分支，已有结果和任务编号保留。来源缺失、网络失败和待查分支分别记录，不能据此宣称全领域检索完整。联网引用信息有短期缓存，过期后重新查询。

新任务默认先显示“入门重点”：按每个种子的研究基础、后续工作和关联证据规模选择代表，兼顾不同引文群落，并保留多种子共同直接引用的基础文献。它是阅读起点，不是完整重要文献清单；完整候选不会因此被删除。手动切换分组后，软件按任务记住选择；新任务仍从入门重点开始。

默认“综合推荐”综合共享参考文献、共同施引、本地题名与摘要匹配和图网络邻近度，并交替展示不同种子、新近工作、基础工作与桥接线索，避免只排高被引论文。结果右侧的“文献分组”菜单可切换研究基础、后续进展、新近相关、桥接线索与待核查；选择“全部候选”恢复整个候选范围。分组只改变展示，不移除候选，菜单底部的“分组依据”逐项说明分类条件。

分组图谱会额外显示所选种子作为关系参照，不计入分组匹配数。后续进展指直接引用种子的文献，新近相关与桥接线索不要求和种子直接连线。

在文献详情中展开“分组依据”，可核查共享参考、共同施引与邻域连接对应的文献。桥接线索表示当前已知图中连接不同邻域，仍需读原文确认研究意义；推荐顺序不等同于论文质量评分。没有摘要或引文信息不足的论文保留在“待核查”，不会自动淘汰。在文献分组菜单中点击“分组依据”可查看分类条件及分组与排序的区别。需要明确限定年份或期刊指标时，仍可自行设置筛选条件。

检索框右侧的“筛选”用于展开排序、年份与期刊指标条件，应用后自动收起；按钮旁的数字表示已设置的条件数量。结果工具栏保留文献分组、图谱／列表切换和“显示设置”三个入口。分组入口与显示设置入口直接显示当前选择，点击可展开修改。显示设置集中提供显示数量、节点颜色与适配画面；显示数量选择“全部同屏”可查看全部筛选结果，选择“自适应”或具体篇数恢复分页。节点颜色独立于文献排序，不改变当前候选顺序；列表模式只显示分页数量设置。以上设置默认折叠，点击面板外或按 Esc 可收起。本机文献总量和引用关系数量可在“使用说明 → 本机资料概况”查看。

## 3. 图谱、筛选与文献详情

搜索框默认用于**查找当前范围的文献**，不启动联网发现。输入题名、摘要关键词、作者、期刊或 DOI，点击“查找”或按 Enter；多个词要求同时匹配，双引号内按原词组查找。在文献探索页，左侧范围下拉可切换本次拓展、本机全部、文献库和阅读清单；在文献库或阅读清单页，查找当前工作区及所选分类，避免混入其他范围。结果显示命中数量，点击“清除”恢复此前范围；零结果时可换词或改查本机全部。

常见气体/气流、流量、超声、PMUT/CMUT 词汇有少量预置中英同义规则，可展开“同义匹配”查看。它不是通用跨语言翻译或 AI 语义检索；其他中文词查不到英文书目时，可补充英文关键词或已有中文译文。

“筛选与排序”可折叠，展开后可按年份、期刊指标和分区缩小范围，或按被引数等条件排序。搜索始终筛选匹配文献，不会因选择“综合推荐”而失效。需要用研究问题安排阅读顺序时，可在筛选面板选择“按输入主题排序（保留候选）”；该操作明确标注只排序、不筛除。缺失指标不等同于数值为零；筛选结果受已有数据覆盖影响。

图谱支持缩放与适配，节点可按被引数、影响因子或年份着色。引用关系通过箭头表示，参考与施引关系使用不同颜色区分。

- 悬停节点可查看题名并强调相关网络。
- 点击节点会锁定该文献的高亮网络；移动鼠标不切换，点击另一节点才切换。
- 点击空白或图外区域可解除锁定，恢复悬停查看。
- 点击文献可打开右侧详情。页签依次为“概览、参考文献、施引文献、网络推荐、资料记录”，不再提供影响整页的阅读/资料模式切换。
- “概览”同时展示原文与中文题名、摘要；两种语言独立显示，不用切换，不会因取得中文而隐藏原文。缺少中文时可点“补充中文译文”，确认后仅翻译缺失的题名与完整摘要，原文及已有人工中文保留；缺少原文摘要时不会凭空生成译文。翻译使用已配置模型，默认不额外查询书目、期刊指标或生成概括。
- 详情保留 AI 速览、全文解读、加入/移出清单三个主要按钮。设为种子、整理文件夹、一般资料补全和 Zotero 同步收在“更多”；“资料记录”集中展示完整书目、指标、发现依据和补全/同步记录，明细按需展开。
- 切换详情页签或后台刷新时，正在编辑的备注保留在当前页面内存；点击保存才写入阅读清单，刷新整个网页前请先保存。
- 未固定的详情侧栏在外部点击时关闭；“固定详情”可保持显示，顶部“文献详情／收起详情”可重新打开或关闭。

图谱默认根据可用画面的宽度和高度自适应调整每页数量，避免小窗口中的节点过密或过小。可在结果区的“每页”选择40、80或200篇，使用底部翻页查看其余结果；在“显示设置 → 显示数量”选择“全部同屏”，可查看当前范围与筛选下的所有文献；文献较多时节点会缩小，选择“自适应”恢复按窗口分页展示。点击图谱右侧的“1:1”恢复标准节点大小，再拖动或滚轮缩放。自动适配不会把少量节点放大到超过标准大小。

图谱与列表展示同一批结果。列表适合逐项比较、批量选择和归类。

## 4. 文献库：积累资料与组织专题

文献库用于保存和长期整理研究资料。探索得到的候选文献可在详情中“保存到文献库”。

### 文件夹与分类

- 点击文件夹区域的“＋”新建文件夹，支持在已有文件夹下建立子文件夹。
- 通过文件夹菜单重命名、修改颜色或移动目录；目录不能移动到自身或其子目录中。
- 使用文件夹搜索、“未分类”和“包含子文件夹”定位待整理文献。
- 同一篇文献可加入多个专题文件夹，避免为不同研究主题重复导入。
- 删除文件夹只移除该目录，不会删除论文或 PDF。

### 拖拽与批量整理

把文献拖入目标文件夹即可归类。也可先多选，再使用工具栏或右键菜单的“添加到文件夹”“移动到”“移出当前文件夹”。“移出”只改变分类归属。

列表支持 Ctrl／Command 点击多选、Shift 连选；Ctrl／Command+A 选择当前显示的结果。整理完成后可通过提示中的“撤销”恢复最近一次受支持的操作。

## 5. 阅读清单：筛选候选与保留判断

阅读清单集中管理准备深入阅读的论文。在详情中点击“加入阅读清单”，并记录阅读备注，用于保留选文理由、阅读结论与待核对的问题。

阅读清单拥有独立的专题目录，同样支持多级文件夹、拖拽与批量整理。其目录与文献库分别管理，可围绕具体的综述、开题或研究问题安排候选论文，而不改变文献库中的长期分类。

### 两个工作区的回收站

文献库和阅读清单各有回收站。删除文献先进入对应回收站，可批量恢复并找回原分类和备注。在阅读清单中删除只影响该清单；文献库回收站中的论文会从其他正常视图中隐藏。

默认保留 30 天，可分别修改，设为 0 表示持续保留。Windows 下到期内容会生成恢复包并转入电脑回收站，原始 PDF 与 Zotero 原库不移动；失败时继续保留在软件回收站。软件关闭期间到期的内容在下次启动时处理。其他系统当前继续保留在软件回收站。

“已转出记录”可用于恢复仍有完整恢复信息的条目。电脑回收站仍由操作系统管理，请按自己的需要保留其中的恢复包。

## 6. 资料补全与后台任务

在单篇详情中选择“补全缺失字段”，或对当前结果批量补全。可选择联网补充书目、查询期刊指标，以及使用 AI 翻译或概括中文内容。

补全按字段检查，已有人工整理保持原样。结果会区分已完整、补充成功、部分补充与未找到，并列出仍缺失的字段；没有可靠来源时保留缺失状态。期刊指标可通过配置数据源或导入指标缓存获得，年份与来源单独标注。

期刊指标库保存在本机，图谱和列表会自动匹配已有 IF、JCR 与中科院分区。同一期刊的多篇论文共享指标，不需要逐篇点击。导入已有缓存后，软件会立即批量匹配本机文献；设置页可查看本机指标库的期刊数量与覆盖情况。

在联网模式下，打开文献结果或完成引文拓展后，缺失指标按期刊集中查询，已取得的结果追加到本机缓存。查询有独立进度，可停止或隐藏；无结果的期刊默认六小时内不自动重复查询，也可点击“补全期刊指标”手动重查。离线模式只读取已有缓存，指标查询不调用 AI。已有有效指标不会被自动覆盖；导入缓存时保留不同年份的历史记录，未记录年份的指标仍标为年份未知。

任务运行时可关闭结果窗口，可拖动的小书灵旁默认显示最近一项任务。点击小书灵查看全部文献拓展、资料补全、期刊指标和全文解读任务；列表按创建时间排列，可查看结果或停止仍在进行的任务。引文拓展没有确定总量时显示发现数和当前轮次，不显示虚假的完成百分比。中断后重试会同时包括尚未开始的论文与仍有缺项的论文。结果栏可以展开、关闭，未完成项可再次尝试。

## 7. 配置 AI 与使用速览

进入“数据与设置 → AI 模型”，默认只展示连接列表。点击“新建连接”或“编辑”打开表单，点击空白、关闭按钮或按 Esc 收起。

1. 选择 DeepSeek、OpenAI、通义千问、Kimi、智谱、Gemini 兼容接口等预设，或填写自定义 HTTPS 兼容接口地址；本机模型网关可使用 `http://127.0.0.1:端口/v1`。预设仅帮助填写地址。
2. 连接名称可自定义，留空使用接口域名。可添加多个 API 密钥；编辑时已保存密钥不回显，保留勾选项即可继续使用，也可取消勾选后删除或补入新密钥。
3. 连接可在未选择模型时先保存；选择模型后才能生成或测试。模型列表可手动逐行填写，也可点击“从上游获取”。如果服务不提供模型列表，手动填入服务商给出的模型 ID。保存后，可直接在列表里选择该服务的模型。
4. 点击“使用”切换当前连接；“测试”发送一条简短请求。密钥发生鉴权、限流或额度不足时尝试本连接的备用密钥。连接失败或内容错误不会伪装成成功。

删除连接只移除本机配置，不会撤销服务商侧密钥。

“学术接口”另行管理 OpenAlex 与 easyScholar 的连接。可新建、编辑、删除和测试；勾选多组启用时形成备用池，也可点击“仅用此组”单独启用该数据源的一组连接。无密钥的公开来源继续使用。密钥与连接配置保存在本机，不随阅读成果或迁移备份导出。

资料补全先保留已有本机字段，缺少摘要时读取已关联原文，再查 Zotero 书目与本机附件；仍缺失才查询在线来源。Zotero 读取会自动尝试，不依赖旧的启用开关；不可用时继续查在线来源。附件索引按批次复制后读取，不修改 Zotero 原库。写回仍须显式选择同步与授权。

引用探索独立于上述补缺策略：本机已有论文仍会参与联网发现新文献，保存记录不表示已经读过。需要暂停外部请求时，在“资料获取 → 更多设置”选择离线使用。

在文献详情中选择“AI 速览”，有结果时直接展示；没有结果、摘要完整且模型可用时自动生成，无需再次确认生成。内容包括中文题名、摘要概括及研究问题、方法、结果和贡献。英文、原始摘要、生成信息与引用按需展开。点击引用定位按钮可回到原文摘要核对。

已有结果不会自动重新生成，需更新时点击右上角“重新生成”；失败时保留旧结果。关闭再打开同篇速览会接续正在进行的请求，不重复提交。新生成和连接测试会请求所配置的模型服务；离线或未配置模型时不自动生成。AI 输出需要结合原文判断，引用命中仅说明文本可定位。

## 8. 全文解读

在详情中选择“AI 全文解读”，进入“论文精读”窗口。没有 PDF 时，可查找已有附件、下载公开全文，或上传本机 PDF；也可前往出版商页面获取文件后上传。公开下载取决于来源是否可访问，不绕过订阅限制。

关联可读取的文献原文后，点击“生成全文解读”，可按以下目录阅读：

- **概览**：了解研究对象、整体思路和主要结果，再决定需要重点阅读的章节。
- **逐节导读**：按照原文章节与小节解释背景问题、方法的用途、实验或分析过程，以及各部分如何共同支撑结论；结合原文理解术语和作者的论证过程。
- **图表说明**：结合正文和图注，说明主要图表及其子图展示什么、在论证中起什么作用、支持了哪些发现。图表依据可同时显示对应PDF原页，便于核对实际图像。
- **结论与局限**：整理原文报告的研究贡献、适用条件与限制，作为比较相关工作的阅读依据。

每处引用可按PDF页码打开原文上下文。“导出解读”生成包含中文Markdown和相关图片的ZIP。图表说明依据正文与图注组织，不保证识别原图中未被文字说明的全部细节；AI解释需要结合原文核对。

“论文原文”卡片中的“管理原文”可查看或更换 PDF，更换后旧解读会标记来源变化，原有结果保留。

PDF 需要可提取文字。扫描件会在生成前提示先完成 OCR，加密文件需先解锁。来源变化或历史结果状态会在窗口中说明，阅读时应对照对应版本的论文。

补全窗口中的“最近任务”、任务详情和重试设置按层返回；关闭或按 Esc 只返回上一层，原来的展开状态和表单保留。读取出版商公开摘要时会核对 DOI 和题名；来源接口未提供摘要、访问失败与模型字段校验失败分别记录。出版商可访问性受来源限制，不能保证每篇都能自动取得。

补全结果中的“查看未补全原因”会列出已记录的来源失败信息，并提供单篇重新补全；缺少原始摘要时可先补充原文。旧任务没有错误明细时会如实说明，不显示无法使用的“展开原因”提示。

## 9. Zotero 同步与成果导出

启动 Zotero 桌面端，在文献详情中选择“同步到 Zotero”。首次连接点击授权按钮，并在桌面弹窗中允许连接，再选择目标集合。

同步窗口支持搜索集合名称或路径、逐级展开子集合，显示当前位置与所选目标。新文献默认选中最近一次成功保存的位置，也可点“最近保存”切换；当前位置优先于最近记录。点击“新建集合”可在所选位置创建子集合，创建后自动选中，同层同名集合直接复用。关闭新建窗口返回原来的保存窗口。更换目标后可选择“从原位置迁移”，同时保留其他集合归属、原笔记和附件。写入书目与阅读内容后会回读核对；刷新集合保留已选目标，列表读取失败时不会擅自改为根目录。连接失效时可展开“连接设置”重新授权。同步默认同时处理 PDF：优先复用目标条目已有的可读附件，其次读取已关联本机原文或 Zotero 附件，再查找可访问的公开 PDF，并自动查询 Zotero 官方公开全文来源。查找、下载、保存与回读在同一次同步操作中完成，不需再点击下载。无可访问版本时显示未取得全文；需要机构权限的PDF不会由公开查询自动取得。新原文以存储附件形式保存在 Zotero，而非只登记链接；传输后回读核对文件内容。失败时保留书目与原附件，可补充原文后重试，不会把书目成功显示成 PDF 成功。此文件上传使用 Zotero 10 及更新版本的官方本地接口。

结果区支持 CSV、RIS 和 GraphML 导出。勾选文献时导出所选，未勾选时可导出当前结果；全文解读使用阅读窗口中的独立导出入口。


## 10. 工作空间、备份与退出

点击左下角的“工作空间”打开管理窗口；小窗口下使用顶部的同名按钮。

- **打开项目目录**：更新并打开“项目文件”。“文献目录”按文献库、阅读清单及多级分类生成可读题名页面；“原文索引”可按题名打开原始PDF。“项目索引.html”可离线检索题名、查看摘要和阅读备注。“备份”“导出”“个人资料”分别保存恢复包、导出成果和自行添加的文件。系统数据库另设入口，运行时不要直接修改或替换。
- **打包备份**：下载一个 ZIP，包含书目、引文、分类、阅读备注、回收站记录、AI 阅读成果、原文来源快照和已关联的可用原文。失效的原文链接会在完成后提示；已有解读保留。备份包含私人阅读资料，应妥善保管。本机模型与数据源连接配置不打包。“个人资料”和“导出”会随备份保存；旧备份不重复打包。备份还会留在“项目文件/备份”中。
- **迁移当前工作空间**：选择一个新的空文件夹，复制并校验后自动重启，后续仍从原来的桌面图标或 `start.bat` 启动。原数据目录及原始文献保留，本机连接配置随迁移复制。
- **从备份导入**：在本机或另一台电脑启动软件，选择新的空目录和备份 ZIP，校验成功后切换到恢复的工作空间。当前数据保留；不会把备份合并进现有文献库。跨电脑导入后重新配置模型与数据源连接。
- **退出软件**：停止后台服务。关闭网页只关闭浏览器页面，后台仍运行；需要完全关闭时使用此按钮。有任务正在运行时，请先等待任务完成。

迁移和导入时请保持窗口打开，等待校验与重启完成。就绪后会自动打开新页面；如果浏览器没有自动打开，再次双击桌面“文献罗盘”图标或 `start.bat`。便携备份只包含已经关联并可访问的原文，不会打包整个 Zotero 文献库，也不会移动或删除原文件。

首次双击 `create-shortcut.bat` 可创建桌面快捷方式。快捷方式采用文献罗盘自带品牌图标；GitHub 首页显示的是仓库里的同一图案。移动程序文件夹后，重新创建快捷方式。


### 重新打开与后台状态

双击桌面“文献罗盘”图标即可重新打开，未创建图标时双击程序目录中的 `start.bat`。后台仍在运行时复用原服务；未运行时重新启动。单独关闭网页不会停止后台，软件中的“退出软件”才会正常停止服务。页面检测到后台中断后会显示重新打开的方法；服务恢复后可点“重新连接”。

### 项目文件管理

“文献目录”和“原文索引”由软件记录生成，分类调整后在工作空间中点击“更新项目目录”，或重新打开项目目录，即可更新。PDF原文件不移动，原文快捷入口继续指向已有文件。请在软件中修改分类、题名和备注；若手动改过生成的页面，更新前会把修改保存到“个人资料/保留的目录修改”。自行添加的文件不会因更新目录而移除。

CSV、RIS、GraphML和全文解读ZIP导出时会同时保存到“项目文件/导出”。个人文件请放入“个人资料”，便携备份会保留其中内容；不要把不希望进入私人备份的文件放在这里。备份与项目资料均属于个人数据，请自行妥善保管。


### 拓展与显示规模

默认一轮、12篇联网查询预算。新任务优先查询种子直接关系，后续结合引文与文本证据安排分支查询；已发现候选不受数量上限截断。查询预算用完后，已有结果保留，可在任务中继续未查分支。数据源覆盖和失败请求仍会造成信息缺口。图谱默认按窗口分页；在“显示设置 → 显示数量”选择“全部同屏”查看当前筛选结果，选择“自动”恢复分页，不改变候选池。


### 网络连接

“设置 → 连接状态”集中显示当前 AI 模型、Zotero 与学术网络。点击“检查连接”或单项“检测”发起检查；AI 会发送一次通用的小型连接测试，不发送论文内容。绿灯表示检查通过，红灯表示失败，黄色表示需登录/验证或结果未确定，灰色表示未检测/待复测。结果附带检查时间，15分钟后或配置发生变化时需重新检测。Zotero 的桌面连接和写入凭据分别说明，未授权时可点击“授权连接”。

展开“出版商访问检查”可选择 Springer Nature、Elsevier、IEEE、Wiley、ACS、Taylor & Francis 或 Oxford Academic。空地址只检查站点连通性；填写所选出版商的论文或 PDF 地址，可继续核查对应原文链接是否返回 PDF。结果仅适用于当前请求和链接，不代表全站订阅或版权授权。检查使用软件的网络设置，不复制常用浏览器的登录状态；需要登录或机构认证时应在对应浏览器完成。

在“数据与设置 → 网络连接”点击“更改”，可选直连（默认）、系统代理或自定义代理。自定义支持 HTTP、HTTPS、SOCKS5，地址包含协议和端口；用户名和密码可选。先测试再保存；测试未保存的配置不会改动当前连接。保存后下一次请求立即使用新设置，不必重启。本机 Zotero 和本地模型始终直连。

网络配置与代理密码仅存于用户数据目录的 private/network.local.json，密码不在页面回显，也不进入源码包或可迁移资料备份。使用代理不代表取得了出版商的访问权限。接口请求支持带认证的代理；出版商浏览器回退暂不使用带认证代理，以免凭据出现在浏览器启动参数中。

资料补全先复用本机和 Zotero，再查询学术接口与可核对的出版商页面；接口没有摘要时继续寻找原文，取得可读 PDF 后提取原始摘要，再生成缺少的中文译文和概括。原文页面须通过 DOI 与题名核对，已有人工内容保持不变。缺失的原文、来源访问失败、译文校验失败分别说明；失败后可在补充原文或调整网络后重试未完成项。只因某个早期来源未返回摘要，不会把最终已补全的论文继续列为待重试。

AI 引用遇到换行、不换行空格等排版差异时，会定位回原文的连续片段，并保存原始字符作为依据。数字、单位、标点和结论内容发生改变仍拒绝写入。


### 本地期刊指标库

在“设置 → 学术接口 → 本地指标库”中可搜索期刊、查看 IF、中科院/JCR 分区、指标年份和来源，并分页浏览。“打开本地表格”会生成并用本机关联程序打开 CSV 查看副本；原始数据库不会交给表格软件直接编辑。若需更新，在副本中修改后通过“导入”写入。

导出支持 CSV 与 JSONL，文件同时保存在“工作空间 → 项目文件 → 导出”。导入支持 CSV、JSONL 和 JSON 数组，沿用逐字段校验，显示接受/跳过数量。可先导出作格式模板。CSV 字段为 name、impact_factor、cas_zone、jcr_zone、metric_year、checked_at、source；指标年份不明时留空，不用查询日期冒充年份。导入仅更新本机指标缓存，并批量补充当前文献缺少的期刊指标，不覆盖已有人工内容。

### 连续补全与并发

正在补全或翻译一篇文献时，可以继续为其他文献发起任务。任务自动排队；在“AI 模型 → 编辑连接 → 同时进行的 AI 请求”设置该连接的并发数（1–8，默认1）。速览、全文解读与补全共用该连接的请求上限。每个补全任务保留提交时的模型选择，切换当前连接不会把已经排队的任务改用另一组模型。同一篇文献不会被两个补全任务同时写入。

点击小书灵查看全部任务；排队任务会自动开始，也可取消。停止等待模型名额的任务，不会再发送新的模型请求。服务重启后，尚未完成的任务标记为中断，已经保存的字段保留，可重试未完成项。

### 文献详情中的常用操作

常用按钮直接显示。“保存到文献库”统一处理收录和归类：默认直接收录，也可以在同一窗口选择一个或多个文件夹。已收录时按钮显示文献库中的当前位置；点击后预选已有分类，勾选或取消勾选即可修改位置，也可改为未分类。归类不会复制或移动 PDF 原文件，操作完成后状态和分类即时刷新。

### 下载、保存与浏览器获取原文

全文解读窗口在正文中显示“生成全文解读”主按钮。原文就绪后点击生成；已有结果时可在正文顶部重新生成。按钮只在用户点击后请求模型。

“论文原文”卡片统一显示文件名、页数和保存状态。“管理原文”可展开更换 PDF、重新查找、浏览器获取及文件位置；“打开文件夹”可直接使用。已有原文不再重复显示“保存 PDF”；只有原文暂存在本机且尚未保存到 Zotero 时，才显示“保存到 Zotero”。没有原文时使用“获取论文原文”或上传本机文件。

点击“获取论文原文”后，软件会查找并尝试下载，取得后显示实际保存状态。“文献原文”设置提供三种保存方式：

- **Zotero 默认位置**：由 Zotero 的附件接口保存和回读核对，采用与浏览器插件一致的实际文件存储位置。集合是分类，不等于磁盘目录；软件不直接向 Zotero 管理目录写文件。暂未连接或保存未完成时，原文暂存在本机，明确显示未完成，可重试。
- **指定目录**：在选择的目录保存一份原文副本，按题名与内容标识命名，已有文件不覆盖；Zotero 原始附件不移动。
- **每次询问**：每次点击下载或上传时，选择本次目录。取消选择不继续本次保存。Windows 使用系统目录选择窗口；其他系统可使用指定目录。

保存完成后显示实际原文位置，可以“打开文件夹”。“上传 PDF”同样遵循保存方式，原来选中的文件不会被移动。

点击“查找全文”先复用本机与 Zotero 附件，再寻找公开原文；常规获取失败时自动进入浏览器获取。保存到 Zotero 时缺少 PDF，也会继续获取，取得后保存到刚选择的位置。任务可在小书灵中查看。

浏览器获取由软件独立运行，不要求安装 Zotero Connector 或其他浏览器插件。程序识别论文页面中的全文信息、PDF 阅读器和内嵌附件，使用采集浏览器的访问状态下载，再核对原文 DOI 或题名，保存到指定位置。首次使用按需准备浏览器组件。网页需要登录或验证时，在采集浏览器中完成后继续；也可以打开常用浏览器取得原文后上传。

Zotero 中已经保存的管理附件、链接附件与插件迁移的原文均可关联，实际位置以 Zotero 返回的路径为准。保存后附件管理工具再次移动文件时，软件按附件标识刷新位置，不要求固定在某个 storage 目录。已有原文不会移动或删除。

机构登录、出版商授权及网站限制仍决定原文是否可访问，不能保证每篇都可自动取得。关闭进度窗口后任务继续，停止则关闭软件拥有的采集窗口，常用浏览器由你控制。

跨电脑备份会复制已关联的原文，不移动 Zotero 原附件；模型密钥、浏览器登录配置与本机路径设置不进入可迁移资料备份。


### 选择需要补充的资料

点击“补全资料”后，先列出当前缺失的书目、期刊指标和中文内容；可全选或逐项勾选。批量操作显示每类资料缺失的篇数。任务只补充所选缺失项，已有内容保持原样；选择中文摘要译文或概括而缺少原始摘要时，会同时勾选原文摘要，供查找和核对。没有配置 AI 时，仍可补书目与期刊指标。

### 入门视图与引用路径

入门重点随候选规模和引文群落自适应选择代表，兼顾研究基础、后续文献与关联证据，不等同于全部重要文献。图中额外显示连接代表文献所需的真实引用路径参照；参照不计入分组篇数。完整候选池始终保留，可在“文献分组”中切换。每个任务记忆自己的分组选择，离开探索页后返回仍保持一致。

### 原文获取需要网页访问时

软件不要求安装浏览器扩展。公开来源不可直接下载时，原文获取窗口会显示当前阶段、来源站点、用时及已知失败原因。点击“打开原文获取窗口”，在该窗口完成机构登录或点击 PDF 下载；可识别的文件会自动核对和关联。网页拒绝访问时不会标记成功。等待窗口最多保留五分钟，可以停止、重试或上传已有文件。

如改用常用浏览器的既有登录，请下载后通过“上传已有 PDF”关联；软件不会自动读取常用浏览器下载目录。Zotero 的书目同步和 PDF 附件状态分别核对，书目成功不代表全文已保存。


### 页面切换与显示记忆

文献探索、文献库和阅读清单分别记住图谱或列表、排序、查找词、年份/期刊筛选、显示数量及当前页。探索任务还分别记住自己的设置；返回时恢复同一组文献和图谱缩放。自动显示数量仍随可用窗口面积调整，改变窗口尺寸可能改变每页数量。分类和阅读清单增删会刷新内容，但不会主动跳回第一页。

### 阅读清单分类与颜色

详情中的“加入阅读清单”可同时选择分类。已加入时显示清单当前位置，点击可调整分类、新建文件夹，或选择“移出阅读清单”。清单分类独立于文献库分类；两个工作区均可使用左侧分类树、子文件夹、拖拽、多选归类与回收站。

新建或编辑文件夹时，可直接选择八种常用标记色，也可自定义颜色。颜色只用于辨认分类，不改变文献内容。

### 获取原文出现操作异常时

页面会给出可读的失败原因；意外服务错误附本地诊断编号，可据此查找运行数据目录下 `private/errors.jsonl`。该记录仅包含异常类型和调用位置，不保存密钥、请求正文或原始授权响应。临时 Zotero 索引使用程序自己的工作目录，原 Zotero 数据库保持只读；临时文件清理受阻不会让已找到的原文失效。
